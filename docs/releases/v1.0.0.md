# RAGLab Agent v1.0.0

首个可交付版本，完成从 Agent Runtime、RAG 与安全工具执行，到 FastAPI、Web、
Docker 和持续集成的完整工程链路。

## 核心能力

- 基于 LangGraph / StateGraph 的多步 Agent Runtime 与 Tool Calling。
- Dynamic Skill Runtime：运行时发现、加载并开放 GitHub Intelligence 更新能力。
- Chroma Dense、BM25、RRF 与 Cross-Encoder 组成的混合检索链路。
- GitHub Intelligence Schema 与受控 Text-to-SQL 查询。
- 会话 Checkpoint、近期上下文、历史检索、长期记忆与上下文预算控制。
- Tool Policy、Fail-Closed 和 HITL 人工审批。
- FastAPI、OpenAPI、多会话 Web UI 与 SSE 运行状态反馈。
- 基于 execution_id 的执行隔离、事件持久化、断线续读和主动取消。
- GitHub 更新子进程终止，以及取消后的 HITL Checkpoint 一致性收尾。
- Docker Compose、非 root 容器、健康检查和持久化数据卷。

## 质量验证

- 40 项 FastAPI 自动化测试全部通过。
- GitHub Actions 自动执行 Python/JavaScript 源码检查与 API 测试。
- GitHub Actions Docker Buildx 镜像构建验证通过。
- 20/20 Agent E2E Benchmark 案例通过。
- 任务完成率、工具路由准确率、检索决策准确率、工具最简调用率、记忆召回
  准确率、人工审批合规率和错误恢复成功率均为 100%。

## 运行要求

- Python 3.11，或 Docker / Docker Compose。
- 完整 Agent 服务需要用户自行提供 `DEEPSEEK_API_KEY`。
- 可选 `GITHUB_TOKEN` 用于提高 GitHub REST API 限额。
- 仓库不包含或发布任何 API Key。

## 说明

Benchmark 会调用真实模型，结果可能受到模型版本、网络与本地数据状态影响。
自动化 API 测试使用 Fake Runtime，不调用真实模型，也不会修改 GitHub Intelligence
业务数据库。
